# Healthcare Resource Demand Forecasting

## Problem Statement
Hospitals frequently experience unexpected surges in-patient admissions, particularly during seasonal outbreaks such as influenza season. These surges catch healthcare staff unprepared, leading to understaffing, overwhelmed resources and a decline in the quality of patient care. This is a critical problem as it directly impacts human lives — both the wellbeing of patients who receive inadequate care and the burnout of healthcare workers

## Solution
This project aims to address this challenge by developing a machine learning model that forecasts periods of high patient admission demand. By predicting surges before they occur, the system gives healthcare workers sufficient time to prepare resources and manage capacity effectively, while also empowering communities to take preventative measures ahead of predicted outbreaks."

## Dataset
Time based data from CDC which contains hospitalisation counts
